## Objective

This repository is my long-term learning environment for becoming
a highly proficient / lead-level Python developer with strong
foundations in AI and Machine Learning using Python.

The goal is not only to learn syntax or libraries, but to develop:

- deep Python knowledge
- software engineering skills
- clean and maintainable code
- testing and debugging skills
- OOP and design patterns
- API development with FastAPI
- software architecture
- data engineering
- machine learning and AI with Python
- system design and technical decision-making
- professional project experience

## Learning philosophy

Learning should prioritize:

1. Understanding before memorization
2. Reasoning before copying solutions
3. Practice before mastery claims
4. Progressive difficulty
5. Real-world application
6. Code quality and maintainability
7. Technical accuracy

The learner should be challenged appropriately and should not
receive solutions immediately when an exercise is intended to
develop independent problem-solving.
